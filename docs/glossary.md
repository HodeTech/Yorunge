# Terimler

| Terim | Yörünge'deki anlamı |
|---|---|
| Görev / task | Kullanıcının tamamlamak istediği iş; örneğin LLM eğitimi veya veri doğrulama. |
| İş akışı / workflow | Bir sonuca bağlı, planlanmış görev adımları ve bunların durumları. |
| Araç sağlayıcısı / tool provider | ForgeLM veya muadili bir haricî aracı sözleşmeyle kullanan adaptör. |
| Hizmet adaptörü | EVREN Platform API, LLM gateway veya SDK ile konuşan sınır. |
| Çalıştırma ortamı / execution backend | İşin çalıştığı yer: yerel süreç, yönetilen EVREN işi veya erişimi doğrulanmış runtime. |
| Profil / context | Hesap/hizmet kimliği referansları ile organizasyon/proje tercihleri. Sırrın kendisi değildir. |
| Yetenek / capability | Görev, hesap, servis, araç ve ortam birleşiminde bir işlemin destek durumudur. |
| Plan | Girdiler, seçimler, etki/maliyet bilgisi ve süre sonu dahil gözden geçirilebilir işlem tanımı. |
| İşlem / operation | Bir planın kalıcı, kimlikli yürütüm kaydı. Uzak iş ve araç run kimliğiyle ilişkilendirilir. |
| Deneme / attempt | Aynı işlemin belirli bir taşıma/yürütme girişimi; her tekrar yeni kullanıcı işi değildir. |
| Unknown | Uzak işlemin gerçekleşip gerçekleşmediği veya yetenek kanıtı henüz belirlenemiyor. Bağlamı belirtilir. |
| Uzlaştırma / reconcile | Yerel kayıt, uzak iş ve artefaktlardan gerçek durumu tekrar belirleme. |
| Artefakt | Model/adapter, metrik, veri raporu veya başka somut çıktı; köken ve hash manifestine bağlanır. |
| CR | EVREN kredi birimi; tahmin, rezervasyon ve gerçekleşen tutar ayrı değerlerdir. |
| Sağlayıcı desteği | Adaptörün uygulanmış ve belirli sürüm/görevde doğrulanmış olması; araç adının katalogda bulunması değildir. |
| Benimsenmiş tasarım | Uygulama PR'larını yönlendiren karar/standart; henüz çalışma zamanı kanıtı yoktur. |
| Dış erişim kapısı | EVREN veya araç tarafındaki yetki, sözleşme veya ortam doğrulanmadan açılmayan özellik koşulu. |
