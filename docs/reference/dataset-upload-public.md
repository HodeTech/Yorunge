## Niyet incelemesi ve dar sonuç

DatasetUploadSummary v2, v2 referansındaki alanlara ek zorunlu nullable `dataset_id`, `approval_status` (`approved|revoked|null`) ve `approval_expires_at` taşır. Dataset ID yalnız mevcut operation.dataset_id’den, onay alanları saved approval’dan gelir; receipt/created_dataset serialize edilmez. Operation yoksa dataset ID null’dır; approved durumu tek başına güncel yetki veya expiry kontrolü değildir. Her summary ≤16 KiB; üst Result v1.operation_id mevcut sözleşmedeki gibi her zaman null’dır. Gerçek kimlik summary.operation_id’dedir; renderer/NDJSON event/error bağlamı bu kimliğe ayrıca bağlanır.

Onaydan önce `review --plan-id` ayrı **UploadIntentReview v1** verir: schema_version=1, kind=dataset_upload_intent_review, summary:DatasetUploadSummary; target (`service_origin`, `api_base_path`, `profile`); selected_owner:UploadOwner, selected_project_id, root (seçilmiş root anchor), manifest:UploadManifestRef, parameters:UploadParameters, storage:UploadStoragePolicy, request_limits:UploadRequestLimits, prepared_at, expires_at. V1 historical review request_limits=null; öteki alanlar tarihsel plan niyetidir. Root device/inode, credential/epoch/clock kimlikleri, grant, receipt ve reported owner/org/name yoktur. Bunlar kullanıcının **istediği** niyettir; provider kimlik/izin kanıtı değildir. Review ≤32 KiB ve mevcut Result/event byte/depth sınırları içinde olmalıdır. Aynı requested name provider cevabında da görülebilir; yasak, baseline’ın veri kaynağı yapılmasıdır. Requested alanlar prepare’de seçili credential literal kuralını geçer; local review env/secret okumaz.

List **DatasetUploadsPage v1**: schema_version=1, uploads (en çok 100 summary), next_cursor:string|null; üst Result ≤1 MiB. Varsayılan limit50, en çok100. Immutable `(prepared_at,plan_id)` ascending keyset, optional exact plan_id filtresi. Tek SQLite snapshot’ında full graph validation ve summary projection yapılır. Byte tavanı sayısal limitten önce dolarsa daha kısa sayfa ve son eklenen satırın cursor’ı verilir; hiçbir satır atlanmaz. Filtrede bulunmayan plan boş sayfadır; show/review bulunmayan plan ID upload_plan_not_found, operation ID operation_not_found hatasıdır.

Summary.cost_bound tam UploadCostBoundV2 değildir; nullable ayrı **UploadCostSummary v1** projeksiyonudur. Tam alanları: schema_version=1, work_digest, maximum_micros, charge_categories, charge_period_start, charge_period_end, post_period_storage, source_id, source_version, checked_at, expires_at. Alan tipleri/period/kategori kuralları private bound’la aynıdır; scope/store/credential/epoch/clock veya root/parameters kopyası taşımaz. Tarihsel quote’u yeniden kullanma veya grant kanıtı değildir. Plan digest ve seçilmiş niyet bağlamı korunur. Nonnull gerçek-bound history fixture’ında kimlik sentinel’ları hem summary hem review wire’da dışarıda kalmalıdır.

## Python API

Bütün girişler senkron; active asyncio loop ve request tipleri state/config/env/ağdan önce denetlenir. Yeni implicit state init yoktur. Public isimler:

- `prepare_dataset_upload(root: Path, *, manifest: Path, owner: UploadOwner, parameters: UploadParameters, project: str, budget_cr: str|None=None, unpriced: bool=False, admission_policy: AdmissionPolicy="verified_only", storage_origin: str|None=None, config: Path|None=None, profile: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadSummary]`.
- `review_dataset_upload(plan_id: str, *, state_dir: Path|None=None) -> Result[UploadIntentReview]`.
- `approve_dataset_upload(plan_id: str, confirmed_digest: str, *, accept_unverified_authority: bool=False, accept_unpriced_cost: bool=False, config: Path|None=None, profile: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadSummary]`.
- `revoke_dataset_upload(plan_id: str, *, state_dir: Path|None=None) -> Result[DatasetUploadSummary]`.
- `start_dataset_upload(plan_id: str, *, config: Path|None=None, profile: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadSummary]`.
- `list_dataset_uploads(*, plan_id: str|None=None, limit: int=50, cursor: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadsPage]`.
- `show_dataset_upload(*, plan_id: str|None=None, operation_id: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadSummary]` (exactly one ID).
- `reconcile_dataset_upload(operation_id: str, *, accept_unverified_read: bool=False, config: Path|None=None, profile: str|None=None, state_dir: Path|None=None) -> Result[DatasetUploadSummary]`.

None/yanlış bool/float/model_construct/nested model_copy/duplicate türleri warning veya ham validation chain olmadan invalid_request/2’dir. Budget_cr yalnız ASCII ondalık string, en çok altı kesir hanesi, nonnegative int64 microcredit’e exact dönüşüm; float/scientific/NaN/işaret/boşluk/Unicode rakam/overflow ret. Budget ve unpriced karşılıklı dışlanır, biri zorunlu; unpriced yalnız explicit_attempt. CLI hyphen değerleri Python underscore policy’ye açık çevrilir. Owner/parameters existing strict DTO’larıdır; raw provider/proof/factory/clock/grant/cost girdisi yoktur.

Prepare explicit project’i config profil tercihinden üstün seçer; account_id owner yerine otomatik konmaz. Approve/start saved profile ve saved project’i varsayılan alır; açık başka profile write scope eşliğini aşmaz. Reconcile açık current profile’a yalnız aynı stable target/store/owner/project içinde izin verir. Context loader local priority ve start existing lookup ardından çağrılır. Start mevcut operation’ı yalnız yerel inceler; source/config/env yeniden açılmaz ve kayıt mutate edilmez. Latched pending/unknown operation_uncertain/5 + aynı ID, unlatched admitted veya failed/cancelled operation_conflict/2 + aynı ID, succeeded yerel Result0 döner. Admission race loser da aynı status/latch sınıflamasını kullanır; existing flag yeni write veya başarı hakkı değildir. Yerel show/list sorguları durumdan bağımsız Result0 kalır; yeni start/create veya retry önerilmez. Koordinatör sonucu elde edilince post-result projection/I-O/SIGINT hataları da bilinen ID’ye bağlanır; terminal kaydı düşürmez. Approve exact saved digest/status/expiry/ack’ı context/env/hash/ağdan önce denetler. Local list/show/review/revoke config/env/hash/ağ gerektirmez.

## CLI ve çıktı

Transfer referansındaki plan/approve/revoke/start/list/show/reconcile ailesine `review --plan-id UUID [--state-dir PATH]` eklenir. Plan owner-user/owner-org zorunlu tek seçim; explicit --project ve --modality zorunlu; budget-cr/unpriced zorunlu tek seçim. License/tags mevcut plan parametreleridir; `--license TEXT`, tekrarlanabilir `--tag IDENTIFIER` ile exact canonical sorted unique seçilir, duplicate tag ret edilir. Diğer singleton option’ların tekrarları, eşitlik ve iki argümanlı biçimler dahil invalid_request’tir. Local komutlara config/profile/project verilmez; approve/start/reconcile proje override kabul etmez. Ortak output ve non-interactive seçenekleri mevcuttur; non-TTY prompt yoktur.

Text plan sonucu ID/digest/status/risk ve `review`/`approve` sonraki adımını gösterir. Review seçili target/owner/project/root/name/modality/private/qty/storage ve maliyet/yetki riskini kısa, etiketli gösterir; CR fiyatı bilinmiyorsa sıfır saymaz. Approve/revoke onay durumunu; start/reconcile/show operation ID/dataset ID/durum/doğrulama seviyesini gösterir. Metadata eşliği remote byte veya yetki doğrulaması diye sunulmaz. Unknown için aynı ID show/reconcile, eksik grafikte güvenli yerel inceleme önerilir; yeni start/create tavsiyesi verilmez.

Text+TTY stderr ilerlemesi en çok 10 Hz coalesce edilir, gerçek source byte sayacından gelir; confirmed dosya/byte ayrı sayılır. Bu sayılar sağlayıcının aldığı veya kalıcılaştırdığı byte iddiası değildir. İlerleme terminalinin kapanması sayacı devre dışı bırakır; buffered stdio kapanış tekrarı da susturulur ve asıl sonucun çıkış kodu değişmez. JSON/NDJSON/non-TTY stderr ilerlemesi yoktur; normal NDJSON tek result olayıdır. Public API callback kabul etmez; CLI’nın özel renderer composition’ı aynı ortak kullanım senaryosuna internal observer bağlayabilir. Callback raw context/baseline/credential/path alamaz. Başarılı Result döndükten sonra renderer operation ID’ye bağlanır; BrokenPipe/UTF-8/SIGINT kaydı yeniden göndermeye dönüştürmez. Invocation sırasındaki hata/iptalde bilinen ID mevcut coordinator/reconciliation güvenli zarfından gelir.

Hata/exit kuralları kopyalanmaz: [v2 gate/read/terminal](dataset-upload-v2.md#işlem-kapıları-ve-current-kanıt), [genel CLI sözleşmesi](cli-contract.md) ve mevcut error kataloğu kanoniktir. API/CLI aynı davranışı taşır; source readonly1/3, local2/4, active write uncertainty5 ve cancel6 ayrımı korunur. Public sentinel kabulü her işlem/format/hata/çıktı zincirinde private receipt alanlarını tarar; requested intent ayrı fixture kaynağıyla sınanır.

İlk Platform upload yolu [ADR-0028](../decisions/0028-platform-upload-content-cardinality.md) uyarınca yalnız tekil SHA-256 içerikli manifestleri başlatır. Yerel inspect/verify aynı hash’li adları korur; public hazırlık uygunluk reddinin [kanonik hata/öncelik kuralını](dataset-transfer.md#p02-2e-kalıcı-yerel-journal-sözleşmesi) kullanır. Manifest/adları bulma ve açık yeni dosya seçimi [kullanım rehberindedir](upload-workflows.md#aynı-içerikli-dosyaları-bulma). Mevcut operation lookup/read/history/revoke biçimi değişmez; error/summary DTO’suna alan eklenmez.
