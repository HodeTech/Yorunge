# Platform upload tüketici sözleşmesi

**Tarih:** 2026-11-02. **Güncellendi:** 2026-11-04. **Durum:** ADR-0026 kapsamındaki gerçek adaptörün dar wire sözleşmesi; yerel uygulama/kabul tamamlandı, bütünleşik canlı upload ve son kaynak/CI kabulü açık. [Politika/current/onay](dataset-upload-v2.md) ve [storage portu](dataset-transfer.md#p02-2f-private-storage-port-sözleşmesi) ayrı kanonik kaynaklardır. Bu belge grant, fiyat veya genel provider API garantisi tanımlamaz.

## Kaynak ve güven sınırı

Kayıtlı profil `evren-platform-observed-upload-v2`, policy 2'dir. [Sabit SDK](https://github.com/speker/evren-sdk/blob/f4eaa4a71f324e61058f24fb90c0aec7a58ae24f/evren_sdk/client.py), [kamu istemcisi/guide kaynak kaydı](../research/p02-2-public-source-receipt.json), [beş GET](../research/p02-2-five-get-observations.json) ve [create/detail/my-role araştırması](../research/p02-2-private-create-observations.md) yalnız tüketilen şekil ve rota kanıtıdır. SDK kurulmaz veya kodu kopyalanmaz. İlk yanlış ID-detail GET'in 405 sonucu tarihsel başarısızlık olarak kalır.

Profil `UploadGrant` veya `UploadCostBoundV2` üretemez. Geçerli gözlemde authority `not_exposed`, maliyet null kalır; default `verified_only` bu profille yürütülebilir olmaz. Yalnız açık `explicit_attempt` ve uygun bütçe/onay kuralları ayrı v2 kapısını açabilir. Bilinen HTTP/schema/owner/private uyuşmazlığı hiçbir zaman oracle yokluğuna dönüştürülemez.

## Ortak decode ve yerel alan güvenliği

Kontrol yanıtı en çok 1 MiB, UTF-8 strict JSON; duplicate/nonfinite/BOM/trailing veri ve mevcut depth/node sınırları ret edilir. Bütün ham ağaçtaki string değerler ve yalnız seçilen şeklin tüketilen sabit protokol anahtarları dışında kalan anahtarlar, **seçili credential'ın literal kuralıyla** taranır. Kısa sırda eşitlik, en az 8 UTF-8 byte'ta alt dize eşleşmesi kullanılır; genel sır veya dönüştürülmüş credential tespiti iddia edilmez. Atılan metadata taramayı aşamaz.

Tek URI istisnası, presign'ın tüketilen exact `presigned_urls[0].upload_url` yaprağıdır: önce sabit hedef/path/tek-key-query politikası ve bütün dinamik raw/decoded değerler doğrulanır, sonra aynı ham URL'nin yalnız bu yapraktaki sabit protokol metni literal karşılaştırmanın dışında kalır. Dataset UUID, raw/decoded query değeri ve kalan bütün ağaç taranır. Aynı URL başka metadata alanında bulunsa istisnayı miras alamaz; generic URL muafiyeti yoktur. Böylece credential `key`, `put` veya `datasets` olduğunda sabit protokol tesadüfü dinamik sır sızıntısı sayılmaz.

Root `success` varsa strict bool=true olmalıdır; 1, false ve string ret edilir. `auth/me` için success=true/data object zorunludur. Diğer object yanıtlarında success varsa data object açılır; success yoksa root doğrudan nesnedir. Liste yanıtı doğrudan array veya success=true/data array olabilir. Metadata public/persistent generic dict'e taşınmaz. Tüketilen alanlar kapalı, strict ve bounded projection'a çevrilir; eksik/yanlış tip kontrol alanı ret edilir.

Her dinamik request segmenti ve body değeri URL/JSON oluşturulmadan önce aynı literal kuralıyla denetlenir; bütün endpoint'e kısa sır eşitliği uygulamak yeterli değildir. Provider username/slug tek ASCII `[A-Za-z0-9_-]` segmentidir (1–128 karakter); slash, percent, dot, query, control ve boş değer ret edilir. Provider UUID canonical herhangi sürümdür; dahili UUIDv4'e çevrilmez. Yerel owner/project/name/license/tag/root alanlarının public özetlere taşınması ayrıca literal denetimden geçer.

Request builder, typed scope/parametreleri de yeniden doğrular; frozen/model_copy/model_construct tek başına doğruluk kanıtı değildir. Python scalar validation JSON serialization'dan önce gelir; integer alana konmuş bool'un 0/1'e normalize edilmesi ret kapısını aşamaz. Private/false, bounded name/tag/license ve canonical scope koşulları request hazırlanırken korunur.

Owned locator için id/name/modality/private/owner_id/org_id/owner_username/slug alanları zorunlu ve strict kalır. Listede `contributions_enabled` bulunmayabilir; eksiklik false/null değeriyle doldurulmaz ve `LocatedDataset` bu politikayı taşımaz. Alan sunulursa yalnız gerçek bool false kabul edilir; true/null/0/string kontrollü reddir. Tam `ProviderDataset` create/detail şeması değişmez: detail bu alanı zorunlu strict false olarak sunmalı ve kalıcı create baseline’ının bütün alanlarıyla eşleşmelidir. Locator veya eksik liste metadata’sı write/proof izni vermez.

4 Kasım [ayrı yetkili tanı](../research/p02-2-implementation-validation.md#4-kasım--owned-listdetail-wire-uyumunun-kapanışı), page_size=20 ile HTTP 200 liste ve detail eşliğini gösterdi; liste contribution alanını sunmadı, detail sundu. Bu gözlem bütün provider sürümleri veya eski 128 isteğinin ret nedeni için garanti değildir. Yerel query sabit 20’dir; otomatik sayfa-boyutu fallback’i yoktur. 128 sayfa, toplam okuma/byte/deadline bütçeleri içinde bir tavandır; tarama tamlığı veya sunucu azami sayfa boyutu iddiası değildir.

Organization context kontrolü kullanıcı üyeliği veya write permission garantisi üretmez. User owner'da org_id nonnull olabilir; kişisel organizasyon ID'si yokmuş gibi varsayılmaz. Create ile sonraki exact-ID detail'deki owner_id/org_id birbirine de eşit olmalıdır. İlk create receipt'inin ID'si hiçbir owned/name aramasıyla değiştirilemez; ID kayıpsa lookup/re-create yapılmaz. [ADR-0027](../decisions/0027-durable-created-dataset-context.md) Accepted: strict create DTO yeni accepted CreateReceiptV2 içinde atomik saklanır; normalizer ham 1 MiB yanıtı tarayıp projekte eder, 2 KiB yalnız canonical receipt'tir. Reader/current expected değeri original veya bu immutable baseline'dır; current owned cevabı tarihsel baseline değildir. Public summary receipt içeriğini yayımlamaz; üretim writer/controller uygulaması p ve sonraki kartların kabulüdür.

4 Kasım [tek-link tanısı](../research/p02-2-implementation-validation.md#4-kasım--exact-ilişki-acknowledgement-uyumu), bare project_id/dataset_id biçimini HTTP 201 ve sonraki membership eşliğiyle gözledi. Bu bağımsız araştırma eski operation’a receipt yazmadı. Generic PUT acknowledgement bu ilişki biçimini kabul etmez; yalnız gerçek link çağrısında consumed ID anahtarı muafiyeti vardır. Başka metadata konumunda aynı anahtar sır taramasını aşamaz.

HTTP/schema hata kodları [v2 mandatory-read tablosuna](dataset-upload-v2.md#tüketici-profili-http-ve-my-role) uyar. Create/link etkili istek tek denemedir; her biri önceden kalıcı intent ve tek permit ister. Başarı decode edilemezse yeni istek yapılmaz, mevcut operation ID ile unknown korunur. Salt okuma pagination list tamlığını veya atomik uzak snapshot'ı kanıtlamaz.

## Proxy upload codec sınırı

İlk provider tüketicisi yalnız `https://api.ssyz.org.tr/api/v1` authenticated API proxy sözleşmesini seçer. Guide bütün API isteklerinde X-API-Key ister; sabit SDK aynı credentialed client'ta `/datasets/{id}/upload/put?key=...` resource-handle rotasını gösterir. Bu kaynak bağı yeniden kontrol edildi; gözlenmiş bir başarılı PUT veya provider key doğrulama garantisi değildir. Başka service origin/API kökü bu profili otomatik miras almaz. Generic direct port yerel olarak testlidir, ancak bu provider için origin/path/expiry/header şeması kapanmadığından public üretici direct seçiminde presign/network öncesi unsupported_combination verir; proxy'ye sessiz dönüş yoktur.

| Aşama | Dar tüketici kuralı |
|---|---|
| Presign body | Dosya başına POST datasets/{id}/upload/presign, `files` tam bir kayıt: filename=manifest göreli yolu, sha256_hash=manifest SHA-256, file_size=manifest boyutu, client_uid=dahili canonical UUIDv4. Path flatten/rename yoktur |
| Presign response | Root veya success=true/data object; presigned_urls tam bir nesnelik array. filename/sha256_hash/request ile eşit; varsa client_uid exact eşit, varsa file_size strict int/eşit. duplicates yok veya boş array; dolu/yanlış tip ret, skip-success yoktur |
| Provider object key | object_key zorunlu, 1–512 ASCII `[A-Za-z0-9_./-]`; boş/dot/traversal bileşeni, URL/percent/query/control ret. Bu yalnız bounded private request girdisidir; regex veya API-key gönderilmesi key'in non-authorizing olduğunu kanıtlamaz. Ham key **hiçbir hedef türünde kalıcılaştırılmaz**, URL gibi yalnız descriptor ömründe tutulur |
| Proxy target | upload_url zorunlu; API-relative `/datasets/{id}/upload/put?...`, API-root-relative veya exact absolute HTTPS hedef olabilir. Wire path tam `{api_base_path}/datasets/{id}/upload/put`; decoded query tam tek `(key, object_key)` çifti. Authority/API kökü/dataset/path/ek auth-signature query/başka key/fragment ret. Özgün query encoding/sırası private target'ta korunur |
| Descriptor control | content_type varsa bounded ASCII MIME; yoksa kaynak uzantısının kapalı MIME eşlemesi veya application/octet-stream. headers/checksum gibi ek zorunlu wire girdileri boş/yok olmalı; desteklenmeyen gereksinim PUT intent'inden önce ret. Presign de etkili aşamadır; kısmi sonuçta yeni hak/re-presign yoktur |

4 Kasım [tek dosyalı storage tanısı](../research/p02-2-implementation-validation.md#4-kasım--put-oksize-acknowledgement-uyumu), PUT HTTP 200/root ok=true/size=79 ve actual source/sent SHA eşliğini gözledi; confirm yapılmadı. Ek alanlar bu gözlemde ad/değer olarak kaydedilmedi. Yeni decoder yalnız bu dosya-byte bağını tüketir; optional key alanını da çağrıdaki volatile değerle karşılaştırır. Bu değer descriptor/call ömründe kalır ve close sırasında call referansı temizlenir; DB/receipt/public çıktı yeni key taşımaz. Link ilişki raw kapsamı bu PUT biçimini miras almaz; protocol key muafiyeti yalnız actual consumed PUT shape’ine aittir.

Sonraki iki farklı içerikli dosyanın PUT/confirm/items eşliği gerçek hesapta geçti. Ancak [r4’te aynı hash/farklı adın üçüncü confirm’i](../research/p02-2-implementation-validation.md#4-kasım--r4-aynı-içerik-kardinalitesi-engeli), skip_dedup=true rağmen created=0/batch_duplicates=1 döndü. Yukarıdaki tam dosya kimliği kabulü bu nedenle henüz doğrulanmadı; yanlış success yoktur. [ADR-0028](../decisions/0028-platform-upload-content-cardinality.md) Accepted: yeni Platform upload’ında tekrarlı hash, HTTP/create öncesi yerel uygunluk kapısında reddedilir; metadata/strict confirm oracle’ı ve geçmiş kayıtlar değişmez. Aynı-hash çoklu adın olumlu uzak desteği P02-R2’de açık kalır.

Son metadata karşılaştırması bütün sayfaları, toplam N'yi, null terminal cursor'ı ve manifestteki exact ad/size/hash bijeksiyonunu ister; fazladan/eksik dosya, tekrarlı/değişen cursor/sayfa/ID/ad veya inconsistent total unknown bırakır. Sayfa/istek/body/attempt toplamları saved v2 work sınırına dahildir. N=128 yerel dosya tavanıdır; provider pagination tamlığı veya uzak atomik snapshot garantisi değildir. Mutable gövde ağdan dönerken bütün raw JSON ve seçili literal guard'ları önce uygulanır; projected metadata byte sınırını aşarak biriktirilemez.

Signed URL, ham query ve raw provider key hiçbir descriptor JSON/receipt/DB/repr/log/exception'a konmaz; bunların hash'i de kalıcı korelasyon kimliği değildir. Proxy expiry yokluğu direct expiry kuralını gevşetmez: proxy authorization güncel bound Platform credential/current-action kapısıdır; plan/approval/lease/request/total marjı her aşamada geçerlidir. Provider header veya query token biçimi değişirse mevcut profil controlled ret verir; sessiz adaptasyon yoktur.

## Yerel dosya bağı ve kalıcılık

Object key'in non-authorizing olduğuna dair provider kanıtı **halen yoktur**; bu kapı kapanmış sayılmaz. ADR-0025'in izin verdiği güvenli file-binding seçilir: yeni observed-v2 producer her operation/dataset/file-index/manifest bağı için bağımsız UUIDv4 üretir. Bu değer raw key/URL veya onların hash'inden türetilmez; client_uid'den de ayrıdır ve HTTP URL/body/header'a **gönderilmez**. Request'teki client_uid ayrı ephemeral korelasyondur.

Mevcut private `StageReceipt.object_key` alanı yeni producer'da bu yerel UUID'yi taşır. Presign→PUT→confirm semantic request digest ve receipt eşliği aynı yerel bağı izler; tam provider body hash'i kaydedilmez. Alan adı tarihsel wire uyumu içindir; public provider object key diye sunulmaz. DDL, eski v1/v2 byte/golden/history ve global opaque-handle validator değişmez; geçmiş kayıt UUID-only diye yeniden yorumlanmaz ve raw handle'ı yeniden gönderilmez. Bu, ADR-0025 kalıcılık sınırını gevşetmez; kanıtlanmamış provider key'i o sınırdan tamamen çıkarır.

Private immutable descriptor, local binding ile operation/dataset/file-index/plan digest/manifest dosyası, exact target ve raw provider key'i aynı çağrı ömründe bağlar. PUT/confirm oluşturulurken expected descriptor bağı yeniden karşılaştırılır. Ayrı dosyaya binding takası, değiştirilmiş descriptor, ortak raw key/farklı local UUID ve yanlış target ret edilir. Provider key yalnız gerçek private PUT query/confirm body hazırlanırken kullanılır; restart yeni write permit veya bu mapping'i geri üretmez. Tam metadata proof ve mevcut accepted graph restart'ta raw key'e ihtiyaç duymaz.

Kabulde provider-key canary'sinin DB/receipt/semantic digest girdisi/çıktı/log/repr/pickle'a taşınmadığı; local UUID'nin ağ request'ine gitmediği; descriptor takası ve ortak raw key'in reddi gerçek coordinator yolunda ayrıca sınanır. Genel sır sınıflandırıcısı veya bütün kısa alt dizelerin tesadüfen hiç görünmeyeceği garantisi verilmez.

## İzleyen dilimler ve kabul

Yerel l/m codec, gerçek HTTP bütçe sayacı, ortak koordinatör ve CLI/Python yüzeyi ayrı commit/ikişer fresh review turuyla tamamlandı. Yukarıdaki sözleşme bu uygulamanın sahibidir; canlı tam upload ve son kaynak/CI kabulü ayrıca kapanır. Her dilimin tamamlanması a/b/c üst kartlarının bütünleşik/live kabulü yerine geçmez.

Kabul: strict bool/UUID/envelope/eksik-null ayrımı; wrong owner/project/private; exact dataset/detail; kısa/uzun sırın dinamik request alanı veya atılan metadata içinde bulunması; duplicate/nonfinite/UTF-8/byte sınırı; create/link ayrımı ve known-negative hata eşliği. Yalnız fixture yeşili canlı provider desteği sayılmaz. Gerçek producer yeni grant/fiyat kaynağı uyduramaz ve frozen araştırma probe'unu ürün modülü olarak import edemez.
