## Kapalı StreamEvent v1

Her olayın tam anahtar kümesi `schema_version`, `stream_id`, `sequence`, `event`, `operation_id`, `payload`'dır. Ek/eksik/duplicate alan, bilinmeyen sürüm, bool/float sürüm veya sıra, NaN/Infinity ve geçersiz UTF-8 reddedilir. `schema_version` strict integer 1; `stream_id` canonical UUIDv4; `sequence` strict integer 1..2^63−1, ilk 1 ve kesintisiz artar. Bir stream aynı stream_id ve bağlanmış operation_id'yi korur; başka invocation'ın olayları birleştirilmez. Operation ID canonical UUIDv4 veya null'dır; normal mevcut komutta null'dır. Yeni stream ID kalıcı resume/dispatch kimliği değildir.

| event | payload | Terminal |
|---|---|---|
| progress | Tam `{stage, completed, total}`; stage `connecting`/`receiving`/`validating`, completed strict integer 0..2^63−1, total aynı aralık veya null; total varsa completed≤total | Hayır |
| result | Çağrının beklenen domain modeline bağlı **mevcut Result v1**, status=completed/operation_id=null; serbest dict değil | Evet |
| error | Güvenli mevcut YorungeError/OperationError zarfı; bilinen code, o kodun kapalı details'i, operation ID bağlamla aynı | Evet |

Result fabrikası mevcut zarfın somut modelini veya yalnız somut model dallarından oluşan tanımlı union’ını korur; data’nın runtime alt sınıfına göre serialization kapsamını genişletmez. Açık BaseModel/None/dict dalı generic yer tutucu olarak kabul edilmez. Outer operation ID akışın bağlamıdır; Result v1'in null ID'sini değiştirmez. Error zarfında operation biliniyorsa aynı ID bulunur. Bu, EOF/trailing/decoder veya output kaynaklı genel hatalarda da `OperationError(code, bound_operation_id)` ile sağlanır; code/exit korunur, details `{reason_code: code, capacity_kind: null}` olur. ID yoksa genel YorungeError zarfı null/boş details kullanır. Error payload mesajı/retryable/details yerel kapalı katalogdan yeniden kurulur; upstream serbest mesaj veya key taşınmaz. Progress provider metni, prompt, raw URL, body/header, env adı veya secret taşımaz. Normal tek-sonuç komut başarıda progress üretmez; sequence=1 tek result emit eder. Metadata `--help`/`--version` makine akışına dönüşmez.

## Byte ve protokol kuralları

UTF-8 compact JSON, bir fiziksel satır ve sonunda LF; string newline'ı JSON escape olur. Tek encoded event LF/CRLF hariç en çok **1 MiB + 1 KiB**; Result payload'ı en çok **1 MiB encoded JSON** olabilir. Böylece 1 MiB JSON sonucu ve bounded wrapper aynı event'e sığar. Producer encoded boyutu/tipi publish'ten önce denetler; aşım output_write_failed/1 olur, çıktı başlamadıysa stdout boş kalır. Sonuç üretilmiş/kalıcı yazı tamamlanmışsa geri alınmaz veya tekrar edilmez. JSON/text için yeni event sınırı uygulanmaz; bu NDJSON'un açık sınırıdır. Payload/frame sınır−1/sınır/sınır + 1 bağımsız fixture'ları zorunludur. Decoder LF veya CRLF kabul eder; boş satır/BOM/lone CR/son LF'siz parça/protokol dışı byte reddedilir. Her record [HTTP/JSON yapısal sayım kuralını](http-transport.md#boyut-ve-süre) kullanır; depth 32/node 65.536 sınır fixture'ları sabitlenir. Bir satırın network chunk veya UTF-8 codepoint sınırında bölünmesi sonucu değiştirmez.

Progress'ler anında doğrulanıp publish edilebilir. Upstream decoder terminal adayını **HTTP response mesajı tam bitene kadar** bounded buffer'da tutar; trailing byte/event veya EOF yerine deadline hatası varsa completed publish etmez. Message EOF, TCP keepalive bağlantısının kapanması demek değildir. Strict decoder hata önceliği: doğrulanmış UTF-8/JSON/sıra/tip/kimlik veya terminalsonrası veri kusuru invalid_response; clean EOF veya reset/truncated HTTP body sonunda yarım line varsa invalid_response; kabul edilmiş en az bir record veya bekletilen terminal varken message tamamlanmadan reset/truncation stream_interrupted; record sınırında terminal olmadan clean EOF, ilk record hiç gelmemiş olsa da stream_interrupted. Header/ilk record öncesi, yarım line olmadan transport hatası transport_failed. Total/phase timeout her aşamada transport_timeout; task cancellation normalizasyonu ayrı kalır. Terminal adayı message EOF'u doğrulanmadan success sayılmaz. Başlamış consumer akışında bu kusur tek güvenli terminal error'a çevrilir, ikinci terminal/başarılı özet eklenmez. Trusted local producer da terminalden sonra emit edemez.

Tüketici okumayı bırakırsa response/iterator context'i kapanır; bütün akış listede biriktirilmez. Aynı task/context ve tek total deadline boyunca okuma, decoder, callback ve backpressure uygulanır. Raw/decoded provider veri ürün stdout'una kendiliğinden akmaz. Reader istekte seçilmiş credential’ı sır denetimine otomatik ekler; çağıranın verdiği ek credential snapshot’ları da korunur. [HTTP provenance kuralına](http-transport.md#boyut-ve-süre) tabi uzun secret canary aynı record'un farklı chunk'larında gelse de doğrulanmadan publish edilemez; kısa sır için tam dinamik değer eşitliği ve sabit schema/mesaj istisnası aynen geçerlidir. Birden çok record'un anlamsal birleşiminden bütün PII/sırları çıkarma garantisi yoktur; uygulama provider metnini progress'e taşımaz.

## CLI, hata ve iptal sınırı

`--output ndjson` mevcut bütün normal CLI komutlarına opt-in seçenektir; `json`/`text` varsayımları ve public Python Result v1 imzaları değişmez. İlk event publish öncesinde hata stdout boş/stderr tek JSON; ilk tam publish sonrasında stdout bir terminal error ve aynı kontrollü exit, stderr'de ikinci JSON yoktur. Parser bu kuralı `--output=ndjson` ve iki argümanlı form için uygular. Kısmi çıktı mümkün olan I/O hatasında tamamlanmış event teslimi iddia edilmez.

Gerçek Task.cancel cleanup sonrası CancelledError'ı yayar. Normal erken aclose/context çıkışı yalnız kaynak kapatır, CancelledError veya terminal event üretmez. İki yol bağımsız test edilir; ikisi de uzak stop değildir. CLI SIGINT request_cancelled/6'dır; kesin yerel rollback veya uzak cancelled garantisi değildir. Critical publish/commit belirsizliği mevcut ilgili hata ve exit 5'i korur. Dispatch latch sonrası start belirsizliği operation_uncertain/5; iş ID'si, kalıcı latch ve retry yasağı korunur. Salt izleme iptali kayıtlı işi provider_cancelled/unknown'a kendiliğinden taşımaz. Trusted provider observation ile kesin cancelled farklıdır.

BrokenPipe output_closed/6: stdout'a yeniden yazma yok, kaynaklar kapanır, safe stderr best-effort. Diğer output I/O output_write_failed/1. Önceden belirlenen operation/config belirsizliği exit 5 önceliklidir; kalıcı terminal başarı output kırılmasıyla değişmez. CLI kapanış flush'ı ham traceback üretmez. Kütüphane CancelledError'ı cleanup sonrası yeniden yükseltir; bu CLI hata normalizasyonu değildir. Tek kanonik kod/exit/tetik tablosu [CLI referansındadır](cli-contract.md#p01-5-hata-kataloğu).
