# Private dataset aktarımı taslağı

**Durum:** ADR-0024/0025/0026 Accepted; d–w yerel temeller, v2 gerçek tüketici/koordinatör/CLI/Python ve ölçüm araçları çalışma dalında verified; üst c nihai kabulü açık. [V2 kanonik politika/maliyet/gate sözleşmesi](dataset-upload-v2.md) aşağıdaki tarihsel v1 kurallarının yeni yazma karşılığını tanımlar. **Tarih:** 2026-11-02. [ADR-0024](../decisions/0024-durable-dataset-transfers.md) ve [ADR-0025](../decisions/0025-isolated-storage-streaming.md) 2026-11-02 kullanıcı yetkisiyle benimsendi. Bu belge mevcut inspect/verify, execution veya jobs sözleşmesini değiştirmez. [Dış kapılar](../roadmap/p02-2-delivery-plan.md#başlangıç-kapıları) kapanmadan remote uygulama hazır sayılmaz.

## Kullanıcı yüzeyi ve uyumluluk

Önerilen ayrı komut ailesi aşağıdadır; **henüz çalışmaz**. Ortak config/profile/state-dir ve text/JSON/NDJSON seçimleri mevcut parse/render ilkelerine uyacaktır; tam argüman/type/DTO ve ortak API imzalarının kanonik uygulama öncesi kaynağı [public yüzey referansıdır](dataset-upload-public.md).

```text
yorunge datasets upload plan ROOT --manifest FILE --name NAME --project UUID
    (--owner-user UUID | --owner-org UUID) --modality MODALITY
    [--storage-origin HTTPS_ORIGIN] [--admission-policy verified-only|explicit-attempt]
    (--budget-cr DECIMAL | --unpriced) [--config FILE] [--profile NAME] [--state-dir PATH]
yorunge datasets upload review --plan-id UUID [--state-dir PATH]
yorunge datasets upload approve --plan-id UUID --confirm FULL_PLAN_DIGEST
    [--accept-unverified-authority] [--accept-unpriced-cost] [...context]
yorunge datasets upload revoke --plan-id UUID [--state-dir PATH]
yorunge datasets upload start --plan-id UUID [...context]
yorunge datasets upload list [--plan-id UUID] [--limit N] [--cursor CURSOR] [--state-dir PATH]
yorunge datasets upload show (--operation-id UUID | --plan-id UUID) [--state-dir PATH]
yorunge datasets upload reconcile --operation-id UUID [--accept-unverified-read] [...context]
```

Python karşılıkları aynı kullanım senaryolarına bağlanacak ayrı upload plan/approve/revoke/start/list/show/reconcile API'leridir; senkron köprü asyncio active-loop/PID/thread kapısını state/credential/etki öncesi uygular. Python çağıranından raw provider JSON, producer/verified flag, authorization listesi, HTTP client veya storage header dict'i alınmaz. JSON/NDJSON Result v1 korunur; bütün dosya/journal stdout'a basılmaz. Bilinen operation ID hem kontrollü hata hem belirsizlik/çıktı iptali yolunda korunur.

Public imza/projeksiyon ve tüketici davranışı P02-2t referansında uygulamadan önce kesinleştirilir; genel CLI kataloğunda ikinci bağımsız hata tablosu tutulmaz. Kayıt bulunamadı, geçersiz plan, kapasite, hedef/yetki reddi ve belirsiz yan etki birbirinden ayrılır. Eski `plan execution` yeni upload planlarını import etmez; `jobs` mevcut execution kayıtlarını göstermeyi sürdürür. Transferin kanonik geçmiş/uzlaştırma yüzeyi bu yeni ailedir. List varsayılan 50/en çok 100 satır, immutable `(prepared_at, plan_id)` keyset cursor ve optional exact plan filtresiyle plan/nullable operation özetlerini verir; ağ/env/hash/onay istemez. Show'da iki ID karşılıklı dışlanır. `show --plan-id` commit edilmiş operation'ı exact FK ile bulur; henüz yoksa operation=null döner, yeni admission/permit üretmez. Admission/ilk ID çıktısı arasındaki kill/BrokenPipe sonrasında kullanıcı yalnız bu yüzeylerle aynı işi bulabilir; start'ı yeniden gönderme recovery önerisi değildir.

## Bağlanan veriler ve otorite

Planın canonical digest'i identity/store/clock, exact Platform target, owner türü/ID, proje ID, private oluşturma parametreleri, root kimliği, immutable manifest, storage policy, quota/deadline ve adapter/policy sürümünü kapsar. Her göreli dosya adı ayrı kimliktir; aynı hash farklı adlar sayısal dedup başarısı altında kaybolamaz. Provider bunu desteklemiyorsa etkiden önce açık sınırlama veya aktarımda doğrulanmış eksik teslim sonucu gerekir; sessiz rename/flatten/skip yoktur.

Kullanıcının owner/project seçimi niyettir; create/link/upload izni değildir. P02-0d sonucu bu yetki yerine geçirilemez. [P02-2a](../roadmap/tasks/p02-2a-private-create.md) exact API-key create kapsamını, project ilişki anlamını ve dataset için güncel upload/read otoritesini kapatır. Desteklenmeyen hedef ve bilinmeyen auth/parent/format bilinmeyen kalır. Profile account/project tercihi yalnız aynı exact hizmette açık doğrulanmış seçimle uyuşuyorsa kullanılabilir; scope'lar birleştirilmez.

Üretim codec'i tüketilen alan/control için strict JSON/type/size ve request/response ilişki doğrulaması yapar. Bilinmeyen ham metadata politikası her endpoint için açık seçilir; discovery'nin metadata istisnası otomatik miras değildir. Literal-secret denetimi seçili credential için mevcut kuraldır: tüm uzunluklarda tam eşitlik, ≥8 UTF-8 byte'ta ayrıca alt-dize. Genel sır/PII sınıflandırması veya kısa sırın sabit protokol metninde hiç görünmeme garantisi verilmez. Dinamik yerel owner/project/name/path alanları da ağ/kalıcılık/çıktı öncesi bu kapsamdadır.

## Kalıcı aşama modeli

**V2 amendment:** [ADR-0027](../decisions/0027-durable-created-dataset-context.md) Accepted; yeni v2 accepted create yalnız CreateReceiptV2, diğer receipt'ler v1. [Kapalı union ve tarihsel geçiş](dataset-upload-v2.md#kalıcı-create-receipt-ve-tarihsel-geçiş) yeni writer/legacy gate ve owner/CAS marker kuralının kaynağıdır. DDL7/2 KiB slot/rezerv değişmez; aşağıdaki tarihsel v1 wire geriye dönük yeniden yazılmaz.

Plan/approval/transfer operation ayrı strict sürümlü kayıtlar; immutable manifest ayrı bounded canonical payload'dır. Yeni 6→7 SQL-only V2 migration yeni boş transfer tablolarını/indekslerini ekler; eski kayıt/payload/checksum için backfill yoktur. Full/hot validation, backup, bakım preview/fingerprint ve global expiry hesabı birlikte gelir. Development tabanı şema 6, bu çalışma dalı şema 7 kullanır; eski migration/manifest/checksum değiştirilmez. Restore/recover'ın operation runtime yasağı korunur.

Owner/fence/CAS ortak güvenlik mekanizmasıdır; transferin 150 s lease'i, tek workflow attempt'i ve stage kotası ayrı aileye aittir. Genel execution'ın 30 s/16 attempt/256 business-event sınırları değiştirilmez veya transfer stage'ine uygulanmaz. Workflow latch ve aşama intent'leri yeniden gönderilemez. Aşama türleri create, project_link, presign, put, confirm; read verification etki izni üretmez. Her aşamanın key'i operation/kind/file index, request digest'i, kalıcı sıra/revision, gerçek UTC/clock alanı ve varsa güvenli resource bağını içerir. Tam private row/receipt alanları, canonical tipler, index/FK ve byte/counter eşitliği P02-2a yerel kayıt adımından önce sabitlenir. Raw signed URL, auth/header/body veya kullanıcı secret'ı journal değildir.

| Sınır | Sonraki izin |
|---|---|
| Henüz intent yok | Güncel bütün kapılar ve önceki aşamanın durable receipt'i ile ilk intent oluşturulabilir |
| Intent commit edildi, receipt yok | Gönderilmiş olabilir; read reconciliation dışında ilerleme yok |
| Strict receipt durable | Yalnız doğru sonraki aşama, yeni son yetki/lease/onay kontrolüyle ilk kez açılabilir |
| Owner/revoke/reset/deadline/yerel girdi değişti | Henüz arm edilmemiş aşamalar engellenir; intent COMMIT öncesi değişimde permit sıfır, sonrasında önceden arm edilmiş tek permit henüz HTTP başlamamış olsa da geri çekilmiş sayılamaz |
| Restart/takeover | Aynı operation üzerinde yalnız read; eksik etkili aşamayı sürdürmek P02-3a'nın ayrı kabulüdür |

Create cevabı yoksa bilinen dataset ID olmayabilir. Yerel operation/correlation korunur; aynı adla bulunan ilk dataset kesin eşleşme değildir. Exact oracle yoksa unknown dürüst son durumdur, yeni create önerilmez. Bilinen dataset için project ilişki listesi ve item metadata observation'ları yalnız kanıtladıkları bağları günceller. `not_found`/401/403/boş liste/eksik page işlemin olmadığını veya tekrarın güvenliğini kanıtlamaz. Değişen sayfa/cursor/çelişkili metadata tamlık iddiasını bozar.

## Gönderilen ve doğrulanan içerik

Plan/approve/start girdi kontrolü manifestin **tüm dosya kümesini** yeniden hash'ler; yalnız manifest dosyasını hash'lemez. Root/ancestor ve dosya descriptor kimliği, byte sayısı, stat imzası ve gözlenen yol değişimi P02-1 modeliyle denetlenir. Transferde descriptor'dan çıkan byte hash'i ayrıca plandaki hash/size ile eşleşir. Bu serial gözlem ve gönderim aralığıdır; atomik filesystem snapshot iddiası yoktur. Gönderilmiş fakat confirm edilmemiş nesne kalabilir; otomatik silme yoktur.

Sonuç üç kanıtı ayıracaktır: yerel güncel içerik kontrolü; gönderilen byte/hash eşliği; exact uzak öğe kimlik/adet/isim/boyut/hash metadata eşliği. Uzak byte'lar indirilip bağımsız hash'lenmediyse `remote_bytes_verified` benzeri bir doğru değer üretilemez. ETag SHA-256 diye yorumlanmaz. Confirm'de `created` sayısı veya HTTP 200/201 tek başına teslim değildir. Duplicate hash birden çok yerel adı kapsıyorsa her adın uzak karşılığı/oracle'ı ayrı raporlanır.

## Sabit sınırlar ve kabul sahibi

Sayısal kararın tek kaynağı ADR-0024/0025'tir: 128 dosya/500.000.000 byte dosya/1 GiB iş; ayrı 30 s yerel validation; 900 s transfer plan/onay/toplam; 150 s lease/120 s PUT/5 s pay; 2 worker/1 MiB chunk/2 MiB queue; 128 plan ve en çok 128 operation; 4.096 dosya/16 MiB canonical payload store kapasitesi. Süresi geçmiş/revoked/başlatılmamış planlar da plan/file/payload kotasına dahildir; niyet yenilemesi yeni plan kimliği üretiyorsa eski kayıt kotadan düşmez. 386 etkili stage intent için en çok birer immutable receipt; iki recovery/terminal rezervi ayrı bounded güncel kontrol kayıtlarıdır, unbounded event history değildir. Global expiry üst sınırı **13.696** (önceki 13.312 + 128 plan + 128 onay + 128 lease), kontrol sınırı **13.697**, sıcak frontier **yedi indeks** olur. Yeni tablolar boşken eski frontier sonucu aynıdır; her yeni expiry/clock mutasyonu ortak kapıyı kullanır. İlk sürüm dosya başına presign/confirm yapar; batch yoktur, response başına JSON 1 MiB kalır. Direct mod için storage origin açık ve digest'e bağlıdır; origin verilmemiş plan proxy-only'dir. Provider cardinality/response/page bütçesi bunlara ek olarak wire araştırmasında sabitlenecektir. Yeni quota mevcut execution kotalarından ayrı sayılır; otomatik geçmiş silme yoktur.

Gerçek loopback TLS/süreç/SQLite kill testleri [P02-2c](../roadmap/tasks/p02-2c-upload-recovery-acceptance.md), streaming/target testleri [P02-2b](../roadmap/tasks/p02-2b-verified-upload.md), gerçek authority/create/link ve local kayıt [P02-2a](../roadmap/tasks/p02-2a-private-create.md) sahibidir. Kanıt raporu ancak gerçek sonuçlarla güncellenir. Canlı kabul için ayrıca exact target/owner/project, sentetik veri, request/byte/süre/tutar tavanı ve kalan private kaynağın sahibi kullanıcı tarafından yetkilendirilir; eski read-only anahtar hazırlığı yazma yetkisi değildir.


## Gönderim ilerlemesi ve yavaş bağlantı

Text/TTY yolunda en çok saniyede 10 kez coalesce edilmiş ilerleme, HTTP taşımasına teslim edilen gerçek kaynak byte sayacından gelir; bu, provider'ın kabul ettiği/kalıcılaştırdığı byte değildir. Kesin onaylanmış dosya/byte ayrıca gösterilir. Her chunk DB/event/NDJSON kaydı oluşturmaz. Non-TTY/JSON/normal tek-result NDJSON çıktısına progress karışmaz; Result/StreamEvent v1 wire'ı değiştirilmez. Python aynı tipli sayacı içeride kullanır; tam public progress imzası API wire kapanışında belirlenir. 500.000.000 byte için 120 s yaklaşık 33,34 Mbit/s payload hızı gerektirir; küçük canlı pilot bu yüksek bant genişliği sınırını kanıtlamaz. Throttle/slow-read/cancel kabulü controlled stop, ID ve sıfır otomatik replay'i sınar.

## P02-2d kapalı yerel plan ve onay wire'ı

Bu bölüm tarihsel v1 yerel kod dilimini kesinleştirir; yeni public producer ve yazma hedefi [v2 sözleşmesidir](dataset-upload-v2.md). Scope-only v1 cost v2 bütçe kanıtı değildir; yeni v1 write yasağı P02-2j uyum adımında uygulanır; mevcut private v1 prototip teslim edilmiş public API değildir. Yeni public upload komutları çalışma dalında uygulanmıştır; [public sözleşme](dataset-upload-public.md) ve [kabul durumu](../roadmap/current.md) ayrıdır. Bütün nesneler strict/frozen/extra-forbid, tüm alanlar zorunlu (nullable dahil), bool sayısal alan değildir. Raw JSON UTF-8, duplicate/nonfinite/BOM/trailing byte reddi; en çok 8 container/50.000 node. Plan/onay encoded byte sınırı 16 KiB; manifest artifact'ı eski Manifest v1 olarak ayrı tutulur ve upload alt kümesinde en çok 256 KiB'dır. Canonical plan/onay UTF-8 JSON `ensure_ascii=True, sort_keys=True, separators=(",", ":"), allow_nan=False`, LF yoktur; Manifest v1'in kendi canonical UTF-8+LF biçimi değişmez. Digest yalnız üst düzey digest alanı hariç bütün planı SHA-256 ile bağlar.

| Tip | Tam alanlar |
|---|---|
| UploadScope | store_id, identity_epoch, clock_generation, service_id=`evren-platform`, service_origin, api_base_path, profile, owner, project_id, credential_id, credential_revision |
| UploadOwner | kind=`user`/`organization`, id |
| UploadRoot | anchor, device, inode |
| UploadParameters | name, modality=`VISION`/`AUDIO`/`NLP`/`MULTIMODAL`/`MEDICAL`, visibility=`private`, contributions_enabled=false, license (string/null), tags (string listesi) |
| UploadManifestRef | digest, content_sha256, file_count, total_bytes; content_sha256 tam Manifest v1 encoded+LF baytlarının hash'idir |
| UploadStoragePolicy | mode=`proxy`/`direct`, origin (string/null); proxy'de null, direct'te kullanıcıca önceden seçilmiş canonical HTTPS/443 origin |
| UploadGrant | schema_version=1, scope (tam UploadScope), permissions, producer_id, producer_version, checked_at, expires_at |
| UploadCostBound | schema_version=1, scope (tam UploadScope), maximum_micros, source_id, source_version, checked_at, expires_at |
| DatasetUploadPlan | schema_version=1, policy_version=1, kind=`dataset_upload_plan`, plan_id, scope, root, manifest, parameters, storage, budget_micros, inputs_verified, grant (UploadGrant/null), cost_bound (UploadCostBound/null), blockers, prepared_at, expires_at, status=`draft`/`prepared`, executable=false, digest |
| DatasetUploadApproval | schema_version=1, approval_id, plan_id, plan_digest, binding_digest, store_id, identity_epoch, clock_generation, approved_at, expires_at, status=`approved`/`revoked`, revoked_at (string/null) |

Internal ID'ler canonical UUIDv4; provider owner/project ID'leri canonical UUID'nin herhangi sürümü olabilir, yeni internal ID'ye çevrilmez. Clock/revision/inode positive int64; device ve para microcredit sayaçları nonnegative int64. CR tam olarak 1.000.000 microcredit'tir; para float kullanmaz. Bir oturumdaki 200 CR agent bütçesi ürünün evrensel fiyatı/limiti değildir. Profile/producer/source kimlikleri mevcut Identifier; timestamps canonical altı haneli UTC'dir. Root anchor P02-1'in ≤4.096 UTF-8 byte no-control/bidi canonical absolute yoludur.

Name 2–128 karakter/≤256 UTF-8 byte, baş/son boşluk/control/bidi yoktur; otomatik trim/rename yoktur. License nullable ≤128 byte; tags en çok 10, tekil ASCII sıralı Identifier'dır. Modality alanının yapısal kabulü gerçek provider format desteği değildir. Storage origin scheme/host/443 dışında path/query/fragment/userinfo taşımayan canonical origin'dir; proxy origin=null olduğunda direct URL yetkisi yoktur.

Grant permissions kapalı yerel görev iddialarıdır: `create_private_dataset`, `link_project`, `read_created_dataset`, `upload_created_dataset`; unique ASCII sıralıdır. Bunlar provider rol/permission adlarının uydurulmuş çevirisi değildir: trusted producer ancak her anlamı resmî/current kaynakla kapatınca üretir. Public API caller grant/cost JSON'u veya verified bayrağı kabul etmez. Grant/cost scope planla birebir, checked_at≤prepared_at<expires_at olmalı; plan kendi 900 s ömrünü ve her mevcut grant/cost expiry'sini aşamaz.

Blockers bağımsız reducer'ın tekil ASCII sıralı sonucudur: inputs_verified=false → inputs_unverified; bütün dört grant izni yoksa authority_unverified; cost_bound=null → cost_unverified; bound>budget → cost_exceeds_budget. Başka blocker, serbest provider metni veya caller'ın seçtiği durum yoktur. Status prepared ancak hiçbir blocker yoksa mümkündür; bu tarihsel hazırlık etkin onay veya dispatch bileti değildir, executable=false kalır. Maliyet bilinmiyor diye sıfır atanmaz.

Intent digest exact `(service_origin,api_base_path,owner.kind,owner.id,project_id,parameters.name)` canonical nesnesinden türetilir; root/credential/epoch/zaman değişimi yeni create hakkı açmaz. Binding digest plan ID/digest/zamanlar ve grant/cost gözlem zamanları hariç bütün semantik gövdeyi kapsar; producer/source sürümü, kapsam ve maliyet üst sınırı değişirse eşleşmez. Onay kendi plan ID/digest/binding/store/epoch/generation'ıyla ve `prepared_at≤approved_at<expires_at≤plan.expires_at` aralığıyla eşleşir; draft plan onaylanamaz. Revoke gerçek revoked_at≥approved_at ister; expired onay da iptal edilebilir. JSON parse/digest eşliği provenance veya insan kimliği kanıtı değildir.

## P02-2e kalıcı yerel journal sözleşmesi

Bu bölüm çalışma dalındaki tarihsel v1 yerel repository tüketicisini tanımlar; v2 union/current/arm/read karşılıkları [ayrı kanonik sözleşmededir](dataset-upload-v2.md#işlem-kapıları-ve-current-kanıt). public CLI/API, gerçek provider producer/adapter ve canlı yazma teslimi değildir. SQL-only V2 adım 6→7 yalnız boş transfer tablolarını/indekslerini ekler. Şema 1–6 SQL/checksum ve eski Plan/Recipe/jobs wire'ları değişmez.

`upload_namespaces` sabit intent digest'i, tam canonical namespace'i ve ilk create intent'inde CAS ile bir kez atanan operation FK'sini; `upload_manifests` canonical Manifest v1 byte'larını (LF dahil); `upload_plans` immutable planı; `upload_approvals` tek onayı/revoke durumunu; `upload_operations` plan başına tek operation ve namespace başına tek create intent sahibini tutar. `upload_stage_intents` sıra/kind/file-index üzerinde tekil, `upload_stage_receipts` intent başına immutable'dır. `upload_controls` operation başına ayrı `recovery` ve `terminal` slotlarıdır. `upload_verifications` tam, sıralı dosya metadata okuma kanıtıdır; uzak byte hash'i iddiası üretmez. Signed URL/header/query hiçbir row veya request digest'ine girmez.

Tüm yeni JSON payload'lar zorunlu alanlı, strict, kapalı ve canonical ASCII JSON'dur; manifest kendi UTF-8/LF wire'ını korur. Satır indeksleri payload'la tam karşılaştırılır; sıcak okuma da plan/manifest/onay/aşama grafiğini doğrular. Kontrolsüz JSON import'u veya caller proof endpoint'i yoktur. `TransferRecord v1`: `schema_version`, `operation_id`, `plan_id`, `plan_digest`, `intent_digest`, tarihsel `approval`, immutable `write_owner_id` ve `write_access_digest`, `created_at`, `updated_at`, `status`, `revision`, `fence`, `observed_identity_epoch`, `observed_clock_generation`, `clock_anomaly`, `lease|null`, `workflow_latched`, `dataset_id|null`, `reason|null`. Overall status `admitted|running|unknown|succeeded|failed|cancelled`; planın hazırlanması operation durumu değildir. Tek workflow attempt vardır; write owner/fence 1 değişmez. Read takeover yeni owner/fence alır, write lease'e dönemez.

`TransferLease`: UUIDv4 owner/identity epoch, positive int64 fence/generation, `mode=write|read`, canonical UTC `renewed_at/expires_at`; TTL ≤150 s. Heartbeat yalnız lease zamanlarını yeniler, semantic revision/fingerprint'i değiştirmez. Her arm aynı geçerli write owner'ın lease'ini aynı transaction'da 150 s yeniler. Token karşılaştırması owner/fence/epoch/generation/mode kimliğini kullanır; süre otoritesi DB'nin güncel lease satırıdır. Read heartbeat açık güncel read grant ile doğrulanır, tarihsel plan credential'ına dönmez. Admission yalnız başarılı ilk çağrıda volatile `TransferWriteAccess` üretir: operation/initial-owner bağı, 32-byte rastgele nonce, issuer PID ve ilk monotonic workflow deadline'ı. DB'de yalnız scoped nonce SHA-256 özeti kalır; nonce/claim Result/row/çıktı değildir. Her write ownership mutasyonu bu exact claim'i ve PID'yi denetler; show, existing admit veya read takeover yeni claim üretmez. Yeni repository fazları ilk nesnenin aynı referansını taşıyabilir; copy/pickle/fork kullanılamaz. Caller deadline ilk workflow deadline'ını uzatamaz. Lease kimliği tek başına yazma izni değildir; aynı UID/Python reflection sandbox'ı iddia edilmez. Yeni business/stage/result/recovery semantic revision'ı artırır. `StageIntent v1`: UUIDv4 intent/operation, sıra 1–386, `kind=create|project_link|presign|put|confirm`, `file_index=null|0..127`, secret-free semantic `request_digest`, issuing write lease, `intended_at/expires_at`. Create/link'te index null; diğerlerinde gerçek dosya index'idir. İstek digest'i plan digest'i, kind/index, manifest dosya bağı, bilinen dataset ve güvenli object key'den türetilir; signed hedefin hash'i değildir. Önceki ilgili aşamanın accepted receipt'i olmadan sonraki arm yapılamaz; farklı dosyalar interleave edebilir.

`StageReceipt v1`: `schema_version`, `intent_id`, `recorded_at`, `result=accepted|rejected`, `dataset_id`, `object_key`, `sent_bytes`, `sent_sha256` (son dördü nullable). Accepted create/link yalnız dataset ID; presign/confirm ayrıca güvenli key; PUT key ve manifestle eşit gönderilen byte/SHA-256 sayacı ister. Rejected gövde bunların hepsini null tutar. Object key yapısal olarak en çok 512 ASCII karakterlik opak handle'dır; raw provider key'in yetki taşımadığı ayrıca kanıtlanmadan onu kalıcılaştıran codec açılamaz. Yeni observed-v2 producer bu kanıtı varsaymaz: [ADR-0025 güvenli file-binding seçeneği](platform-upload-consumer.md#yerel-dosya-bağı-ve-kalıcılık) uyarınca bu tarihsel adlı private slotta bağımsız yerel UUID tutar; raw provider key/URL yalnız ephemeral descriptor'dadır. Eski payload/validator yeniden yazılmaz; yerel binding ağda provider key olarak kullanılmaz. Kesin ret sırasında başka cevapsız intent varsa overall unknown kalır, yeni arm kapanır; mevcut inflight receipt'leri kaydedilebilir. Hepsinin sonucu kesinleşince failed terminal olur. Diğer arm edilmiş/inflight etkiler geri alınmış sayılmaz. Terminal kayıttan yeni arm veya kayıt değişimi yoktur.

`TransferControl v1`: `kind=recovery|terminal`, operation/revision, UTC `observed_at`, identity epoch/generation, kapalı reason ve nullable `verification_digest`. Reason kataloğu `identity_reset|lease_expired|clock_changed|request_uncertain|approval_revoked|approval_expired|provider_rejected|local_cancelled|verified`'dır. Recovery son yerel marker'ı aynı ayrılmış slotta günceller; terminal immutable'dır. `TransferVerification v1`: dataset/project, kapsamlı güncel read grant, `observed_at`, sıralı 1–128 `VerifiedFile` (`file_index,item_id,path_digest,size_bytes,sha256`). Item ID'leri tekildir. Başarı ancak bütün create/link/presign/PUT/confirm receipt'leri ve tam metadata kanıtı varsa oluşur. Aynı clock epoch/generation içinde gözlem son confirm receipt'inden önce olamaz; predecessor receipt'i de sonraki intent'ten sonra olamaz. Reset/clock generation değişiminde UTC farklı nesiller arasında sıralanmaz: güncel read grant kapsamı ve o neslin recovery marker zamanı alt sınırdır; böylece ileri saat geçmişi reset sonrası fresh okumayı bloke etmez. Bu kurallar hem kayıt yazımında hem warm/full graph doğrulamasında uygulanır. Eksik create ID'si veya eksik receipt'i yalnız ad/ID benzerliğiyle başarıya çeviren yol yoktur; gerçek exact reconciliation oracle'ı olmadan unknown kalır.

Kota hesabı: retained plan ≤128, operation ≤128, plan başına sayılan mantıksal dosya toplamı ≤4.096. 16 MiB payload bütçesi namespace/manifest/plan canonical byte toplamı + her plan için gelecekteki onay/revoke'a ayrılmış 16 KiB + her operation'ın admission'da ayrılan `36 KiB + (2 + 3N)×4 KiB + N×512 byte` rezervidir. Bu rezerv operation (16 KiB), her olası intent+receipt (2+2 KiB), iki kontrol (4 KiB) ve doğrulama (`16 KiB + N×512 byte`) için yeterlidir. Çocuk satırlar bu rezervin içinde sayılır; iki kez sayılmaz. Tavanlar eşzamanlı garanti edilen kapasite değildir; 16 MiB önce dolabilir. Admission kapasite hatasında business savepoint rollback olur; henüz etki/permit yoktur. Ayrılmış alan recovery/reset/terminal için korunur; hiçbir geçmiş otomatik silinmez.

Yerel `StateUploads` save/show/list/approve/revoke/admit/renew/arm/receipt/stop_local/acquire_read/verified işlemleri aynı clock transaction'ını kullanır. Show'da yalnız bir plan veya operation ID; list'te varsayılan 50, en çok 100 ve canonical `(prepared_at,plan_id)` keyset cursor vardır. List yalnız plan ID/digest/hazırlık/status ve nullable operation ID/status özetlerini tutar; bütün journal'ları sonuçta biriktirmez. Create intent henüz yoksa terk edilmiş/pre-dispatch plan farklı bir planla yenilenebilir; ilk create intent'inin namespace bağı commit edildikten sonra bu yol kapanır. Bunlar env, input hash, ağ veya etkin onay istemez. ID ilk çıktıdan önce kaybolursa aynı plan lookup'ı bulur; tekrarlanan admit yalnız mevcut kaydı döndürür, lease/attempt/permit üretmez. Save/admission/arm güncel credential ID/revision, store/epoch/generation, current input/authority/cost snapshot ve etkin onayı son transaction'da karşılaştırır. Eski sahibin geç yazısı lease/fence/CAS ile reddedilir. Intent COMMIT'inden sonraki revoke/reset, önceden verilmiş permit'i dış sistemden geri çekmez. Commit sonrası son kapı başarısızsa ID'li `operation_uncertain` kullanılır, intent silinmez.

Yeni kapalı yerel hatalar: `upload_plan_not_found`, `upload_plan_not_valid`, `upload_capacity_exceeded` → exit 2. Gerçek HTTP iş kotasının ayrı `upload_limit_exceeded` / exit 2 kuralı [HTTP bütçe sözleşmesindedir](dataset-upload-http.md#hata-ve-kabul); kalıcı store doluluğu değildir. Koordinasyon hatası mevcut OperationError zarfıyla operation ID'yi korur; ikinci bağımsız Result/error şeması yoktur. Güncel state mutation/store fazı mevcut 5 s deadline kontrol noktalarına tabidir; disk I/O için katı fiziksel süre garantisi değildir.

Şema 7 global frontier üç upload indeksi ekler: plan expiry, approval expiry ve operation lease expiry. Toplam **13.696 sınır / 13.697 kontrol / yedi sıralı indeks**; eski runtime'lar yalnız mevcut tablolarını sorgular. Reset preview **v4**, önceki v3 alanlarına `upload_plan_count`, `transfer_operation_count`, `nonterminal_transfer_count`, `unknown_transfer_count`, `transfer_fingerprint` ekleyen snapshot kullanır. Snapshot fingerprint'i plan/onay ve operation semantic state'ini kapsar; yalnız heartbeat zamanı hariçtir. Reset, gelecekteki UTC'ye takılmadan yeni epoch altında lease'i kaldırır; intent varsa unknown, yoksa cancelled; geçmiş/namespace/latch korunur. Restore/recover runtime yasağı sürer. Eski v2/v3 tipleri tarihsel migration/test tüketicileri için korunur.


## P02-2f private storage port sözleşmesi

Default `StorageTarget.literal_policy=all_parts` generic URI literal denetimini korur. Yeni gerçek tüketici için yalnız kayıtlı `platform_proxy_v2` politikası seçilebilir: constructor exact resmi origin/API kökü/dataset upload/put ve tek decoded key query biçimini doğrular; sonra dinamik dataset UUID ile raw/decoded query değeri taranır. Başka origin, direct hedef, rota veya query bu sabit protokol istisnasını kullanamaz. [Tüketici yaprağına bağlı raw-tree kuralı](platform-upload-consumer.md#ortak-decode-ve-yerel-alan-güvenliği) adjacent metadata'yı muaf tutmaz. Bu private seçenek public config/flag değildir; eski service HttpRequest/default storage tüketicileri değişmez.

**Çalışma dalı durumu:** 4.1 hedef/request/source ve 4.2 DNS/peer/shared-client dilimleri kendi iki fresh review turu ve doğrulanmış bulgu düzeltmeleriyle tamamlandı; P02-2f verified. [Yerel kabul kaydı](../research/p02-2-implementation-validation.md#adım-42-fresh-r2) development teslimi veya gerçek provider upload kabulü değildir.

Bu yerel port gerçek provider presign/confirm codec'i veya public upload CLI/API değildir. `StorageRequest` yalnız PUT taşır: private `StorageTarget`, lazy owned `ByteSource`, MIME, nullable SHA-256 header kodlaması, nullable proxy credential ve seçili literal denetim sırları. User header dict'i/body bytes veya keyfî yöntem almaz; response sınırı değişmez 64 KiB'dır. MIME ASCII media-type sözdizimindedir; checksum header adı/değeri yalnız önceden bilinen digest'ten kapalı `none|sha256_hex|sha256_base64` politikasıyla üretilir. Direct header-signed auth yoktur. Hedef/source/request repr'i URL/path/credential göstermez.

`StorageTarget` iki kapalı varyant taşır. Proxy: normalize Platform service target, exact dataset UUID ve o dataset altındaki doğrulanmış path; credential yalnız evren-platform/aynı target/X-API-Key olabilir. Direct: planın önceden seçtiği exact origin ve trusted tüketicinin önceden belirlediği path-prefix, private signed URL ve canonical UTC expiry. 4.1 constructor expiry'nin varlığını/kanonik biçimini doğrular; clock'a bağlı freshness/5 s marjı 4.2'de bağlantıdan hemen önce tekrar uygulanır. Eski bir descriptor oluşturulabilmesi onu gönderilebilir yapmaz. Prefix/allowlist yanıttan türetilmez veya genişletilmez; gerçek provider prefix'i ayrı codec kabulüdür. Her URL ≤16 KiB ASCII; authority, path ve query ADR-0025'e göre ayrı doğrulanır. Dinamik path bileşenlerinin kabul edilen raw/decoded katmanları, query'nin tek decoded key-value'ları ve MIME/checksum değerleri seçili literal sır kuralıyla denetlenir; sabit Content-Length/Accept-Encoding protokol değerleri bu taramanın girdisi değildir. HTTPX prepared URL/header eşliği ağdan önce zorunludur.

Transfer'e özel transport facade, mevcut `HttpxTransport` service open mekanizmasını ve tek client/pool/two-slot sahipliğini koruyarak `open_storage` ekler. Normal HttpSession/discovery politikası değişmez. Transfer session'ının bütün yeni TCP bağlantıları bounded DNS+public-IP+peer guard üzerinden geçer; service ve storage ayrı pool açmaz. HTTPcore'un public async pool/backend arayüzü için doğrudan hafif bağımlılık açıkça bildirilir; SDK veya eğitim paketi eklenmez. DNS en çok 16 A/AAAA kayıt, bağlantı tek seçilmiş doğrulanmış IP, original SNI/Host/certificate; karışık yasak cevap/peer uyuşmazlığı HTTP byte'ından önce reddedilir. Test backend/resolver/CA injection yalnız private test composition'dır.

ByteSource descriptor'ı construction'da I/O yapmaz. İlk okuma ve kapanış aynı async task/loop/thread/PID'de; absolute root/ancestor no-follow zinciri, captured root dev/inode ve relative leaf regular-file/size kontrolü vardır. Her pull en çok 1 MiB okur; cooperative checkpoint bloklar arasındadır. İki worker pull temellidir, ayrı üretici kuyruğu veya bütün dosya buffer'ı yoktur; uygulama teslimindeki chunk sınırı toplam 2 MiB, HTTP/runtime buffer'larının gerçek RSS'i ayrıca ölçülür. `sent_bytes` source→transport teslim sayacı, `sent_sha256` ve `complete` final stat/root/ancestor/hash kontrolünden sonra anlamlıdır; bunlar provider byte kabulü değildir. EOF'tan önce veya hash/kimlik değişiminde confirm açılmaz. Kaynak kısa/uzun okuma, replacement, root/ancestor değişimi, deadline ve cancel'da kontrollü kapanır. Kaynak explicit owned async iterator/context kullanır; async-generator GC/finalizer ile başka task'ta kapatma yolu yoktur. Copy/pickle/fork ile descriptor paylaşımı açılmaz. Bloke os.read/DNS I/O zorla durdurma veya katı fiziksel süre garantisi verilmez.

`StorageRequest` hazırlanırken size/SHA-256 snapshot'ı alınır; kaynağın daha sonraki metadata değişimi Content-Length'i değiştiremez ve ağdan önce reddedilir. `TransferSession` direct origin'i construction'da plandan alır; presign descriptor'ı kendi origin'ini session'a ekleyemez. DNS ve numeric TCP bağlantısı ortak connect deadline'ını paylaşır; her yeni bağlantıda tüm cevaplar public olmalı, seçili numeric IP gerçek peer ile eşleşmelidir. Pool'dan tekrar kullanılan bağlantının peer'i HTTP read/write öncesinde yeniden denetlenir. Certificate doğrulaması ve original hostname/SNI korunur.

Storage response yalnız raw incremental okunur; identity encoding, finite deadline, phase/pool ve size guard'ları mevcut ortak mekanizmayla korunur. Source tamamlanmadan gelen erken success, redirect/429/5xx/connection failure/partial PUT ikinci deneme üretmez. `StorageResponse.sent_bytes/sent_sha256` yalnız transport'a teslim edilen ve EOF'ta hash/stat kontrolünü geçen yerel byte kanıtıdır. Actual provider success oracle'ı bu portun 2xx bilgisinden ayrı codec'te doğrulanır; 2xx/ETag metadata/remote SHA-256 kanıtı sayılmaz. Task.cancel cleanup sonrası CancelledError yayar; normal context exit kendi başına cancel üretmez.
