# Analiz yönetimi

**Güncellendi:** 2026-10-27.

Bu dizin yerel analiz arşivinin yönetim sınırını tanımlar. `private/` altındaki dosyalar Git'ten dışlanır; repo, paket, site ve yayımlanabilir dokümantasyonun parçası değildir.

Özel analiz dosyaları kaynak koddan, ürün belgelerinden, changelog'dan veya commit/PR içeriklerinden referans verilmez. Gerekli kararlar kendi kanonik belgesinde bağımsız anlatılır; dış hizmet/araç sözleşmeleri resmî kaynaklarla desteklenir. Bu indeks özel içerik listesi veya arşive giden içerik bağlantısı tutmaz.

Arşivdeki tarihsel dosyalar kendi bağlamında korunur. Genel belge doğrulama ve yayın araçları yalnız paylaşılabilir kapsamı tarar. Dışlama, Git yanında paket/site üretimi sırasında da denetlenir. Kurallar: [belgeleme standardı](../standards/documentation.md), [yayın standardı](../standards/git-release.md).
